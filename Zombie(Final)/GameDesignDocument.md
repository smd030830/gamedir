# Zombie Survival 추가 기능 기획서

## 1. 개요

`Zombie Survival`은 제한된 공간에서 몰려오는 좀비를 처치하며 최대한 오래 생존하는 3D 생존 슈팅 게임이다. 기존 게임의 기본 구조인 이동, 사격, 체력, 탄약, 코인, 웨이브 시스템을 유지하면서 플레이 흐름을 더 명확하게 만들고, 전투 선택지를 늘리는 방향으로 기능을 추가했다.

이번 개선의 핵심은 다음과 같다.

- 인트로 씬과 엔딩 씬을 추가해 게임 시작과 종료 흐름을 완성했다.
- 플레이어가 마우스 방향을 바라보도록 회전 방식을 변경했다.
- 샷건 모드, 실드 아이템, 돌진 좀비, 랭킹 시스템을 추가해 게임성을 확장했다.
- 자율 기능으로 대시 기능을 추가해 위기 상황에서 회피할 수 있는 조작 요소를 넣었다.

## 2. 게임 방향성

게임의 방향성은 단순한 좀비 처치 게임에서 벗어나, 플레이어가 상황에 따라 선택하고 대응하는 생존 액션 게임으로 발전시키는 것이다.

기존 방식은 좀비를 피하면서 총을 쏘는 구조가 중심이었지만, 추가 기능을 통해 플레이어가 더 적극적으로 전투 흐름을 조절할 수 있게 했다. 마우스 조준은 조작의 직관성을 높이고, 샷건 모드는 가까운 거리에서 강한 범위 공격을 가능하게 한다. 실드 아이템과 대시 기능은 위험한 상황에서 생존할 수 있는 수단을 제공하며, 돌진 좀비는 플레이어가 계속 이동하고 판단하게 만드는 압박 요소로 작동한다.

또한 인트로 씬과 엔딩 씬, 랭킹 시스템을 추가해 게임의 시작과 끝이 명확해졌고, 플레이어가 높은 점수를 목표로 반복 플레이할 이유를 만들었다.

## 3. 추가 기능 기획

### 3.1 인트로 씬

게임을 실행했을 때 바로 전투가 시작되지 않고, 인트로 화면에서 게임 제목과 간단한 조작 안내를 보여준다. 플레이어는 `Enter`, `Space`, 마우스 클릭 또는 `START` 버튼을 통해 메인 게임으로 진입할 수 있다.

이 기능은 게임의 시작 흐름을 자연스럽게 만들고, 처음 플레이하는 사람이 조작 방법을 확인할 수 있도록 하기 위해 추가했다.

### 3.2 엔딩 씬

플레이어가 사망하면 기존 게임오버 UI 대신 엔딩 씬으로 이동한다. 엔딩 씬에서는 최종 점수와 랭킹을 보여주며, `RETRY` 버튼으로 다시 플레이하거나 `INTRO` 버튼으로 시작 화면으로 돌아갈 수 있다.

이 기능을 통해 게임 종료 후 결과 확인, 재도전, 시작 화면 복귀 흐름이 명확해졌다.

### 3.3 마우스 기반 회전

기존에는 좌우 방향키 입력으로 캐릭터가 회전했지만, 변경 후에는 마우스 위치를 기준으로 캐릭터가 바라보는 방향이 결정된다. 카메라에서 마우스 위치로 Ray를 쏘고, 플레이어 높이의 평면과 만나는 지점을 계산해 그 방향으로 캐릭터가 회전하도록 구현했다.

이 변경으로 플레이어는 이동과 조준을 분리해서 조작할 수 있으며, 좀비를 향해 더 빠르고 직관적으로 사격할 수 있다.

### 3.4 샷건 모드

새로운 총 기능으로 샷건 모드를 추가했다. 샷건팩을 획득하면 일정 시간 동안 기존 총이 샷건 모드로 변경된다. 샷건 모드에서는 한 번 발사할 때 여러 개의 산탄을 퍼뜨려 가까운 범위의 적에게 피해를 줄 수 있다.

일반 총은 한 방향으로 정확히 공격하는 데 유리하고, 샷건은 좀비가 가까이 몰려올 때 여러 적을 상대하기 좋다. 이를 통해 무기 사용 상황에 차이를 만들었다.

### 3.5 돌진 좀비

좀비 종류를 다양화하기 위해 `Charger` 변종을 추가했다. 돌진 좀비는 일반 좀비보다 공격력이 높고, 일정 거리 안에 플레이어가 있으면 짧은 시간 동안 빠르게 돌진한다.

이 좀비는 웨이브가 진행된 뒤 확률적으로 등장한다. 플레이어가 한 자리에서 계속 사격만 하지 않고, 위치를 바꾸거나 대시를 사용해 회피하도록 압박하는 역할을 한다.

### 3.6 실드 아이템

기존 아이템인 코인, 체력, 탄약 외에 실드 아이템을 추가했다. 실드팩을 획득하면 일정 시간 동안 추가 보호막이 생기며, 좀비에게 받는 피해를 먼저 막아준다.

실드 아이템은 플레이어가 체력이 낮거나 좀비에게 둘러싸였을 때 생존 가능성을 높여주는 방어형 아이템이다.

### 3.7 랭킹 시스템

게임이 끝났을 때 최종 점수를 저장하고, 상위 5개의 점수를 랭킹으로 보여주는 시스템을 추가했다. 점수는 `PlayerPrefs`를 사용해 로컬에 저장되며, 엔딩 씬에서 랭킹 목록으로 출력된다.

랭킹 시스템은 플레이어에게 더 높은 점수를 목표로 다시 플레이하게 만드는 동기 부여 요소다.

### 3.8 대시 기능

자율 기능으로 대시를 추가했다. 플레이어는 `Shift` 키를 눌러 짧은 거리를 빠르게 이동할 수 있다. 대시에는 쿨타임이 있으며, 화면 왼쪽 아래에 대시 가능 여부와 남은 쿨타임이 표시된다.

대시 중에는 좀비의 피해를 받지 않도록 처리해, 단순 이동 기능이 아니라 위기 회피용 생존 기술로 사용할 수 있게 했다. 돌진 좀비나 다수의 좀비에게 둘러싸였을 때 빠져나오는 데 유용하다.

## 4. 구현 시 에러 사항 및 해결법

### 4.1 마우스 회전 반응이 느린 문제

처음 마우스 기반 회전을 적용했을 때 캐릭터가 마우스 방향을 너무 느리게 따라가는 문제가 있었다. 원인은 `PlayerMovement` 스크립트의 기본 회전 속도를 높여도, 플레이어 프리팹에 저장된 `rotateSpeed` 값이 더 낮게 오버라이드되어 있었기 때문이다.

해결 방법으로 스크립트의 기본 `rotateSpeed` 값을 높이고, `Player Character.prefab`에 저장된 실제 회전 속도 값도 함께 수정했다. 이후 마우스 조준 반응이 더 빠르게 개선되었다.

### 4.2 인트로/엔딩 씬 전환 문제

씬을 추가해도 빌드 설정에 등록하지 않으면 `SceneManager.LoadScene()`으로 씬 전환이 정상적으로 되지 않을 수 있다.

이를 해결하기 위해 `Intro`, `Main`, `Ending` 씬을 Unity Build Settings에 등록했다. 인트로에서는 `Main` 씬으로 이동하고, 게임 종료 시에는 `Ending` 씬으로 이동하도록 구성했다.

### 4.3 랭킹 점수 전달 문제

게임 종료 후 엔딩 씬으로 이동하면 기존 게임 씬의 오브젝트가 사라지기 때문에, 최종 점수를 엔딩 씬에서 바로 참조하기 어렵다.

이를 해결하기 위해 `GameSession` 정적 클래스를 만들어 마지막 점수를 저장하고, `RankingSystem`을 통해 점수를 `PlayerPrefs`에 등록했다. 엔딩 씬에서는 `GameSession.lastScore`와 `RankingSystem.FormatRanking()`을 사용해 최종 점수와 랭킹을 표시했다.

### 4.4 보너스 아이템 프리팹 연결 문제

샷건팩과 실드팩을 별도 프리팹으로 모두 제작하면 씬이나 스포너에 직접 연결해야 하는 작업이 늘어난다.

이를 해결하기 위해 `BonusItemSpawner`에서 런타임에 기본 도형 오브젝트를 생성하고, 그 오브젝트에 `ShotgunPack` 또는 `ShieldPack` 컴포넌트를 붙이는 방식으로 구현했다. 이렇게 해서 별도 프리팹 연결 없이도 보너스 아이템이 자동으로 생성되도록 했다.

### 4.5 대시 중 피격 처리 문제

대시 이동만 추가하면 좀비와 겹쳐 지나갈 때 여전히 데미지를 받아 회피 기능으로서 의미가 약해지는 문제가 있었다.

이를 해결하기 위해 `PlayerMovement`에 `IsDashing` 상태를 만들고, `PlayerHealth.OnDamage()`에서 대시 중이면 데미지 처리를 하지 않도록 했다. 그 결과 대시는 짧은 무적 시간이 있는 회피 기술로 작동하게 되었다.

## 5. 기대 효과

추가 기능을 통해 게임의 완성도와 반복 플레이 요소가 강화되었다. 인트로와 엔딩 씬은 게임의 흐름을 명확히 만들고, 랭킹 시스템은 점수 경쟁 요소를 제공한다. 마우스 조준, 샷건, 실드, 대시는 플레이어 조작의 재미를 높이며, 돌진 좀비는 게임 난이도와 긴장감을 증가시킨다.

결과적으로 기존의 단순한 좀비 처치 게임에서, 다양한 상황에 맞춰 공격과 회피를 선택하는 생존 슈팅 게임으로 발전했다.
